# KAFKA PRODUCER

## kafka_producer.py

```python
from kafka import KafkaProducer
import json
import time
from datetime import datetime
import random

producer = KafkaProducer(
    bootstrap_servers='localhost:9092',
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

while True:

    data = {
        "order_id": random.randint(1000, 9999),
        "customer_id": random.randint(1, 100),
        "amount": random.randint(100, 10000),
        "timestamp": str(datetime.now())
    }

    producer.send("retail_orders", data)

    print("Sent:", data)

    time.sleep(2)
```

# PYSPARK STREAMING CONSUMER

## spark_streaming_job.py

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import *

spark = SparkSession.builder \
    .appName("RetailStreaming") \
    .getOrCreate()

df = spark.readStream \
    .format("kafka") \
    .option("kafka.bootstrap.servers", "localhost:9092") \
    .option("subscribe", "retail_orders") \
    .load()

json_df = df.selectExpr("CAST(value AS STRING)")

parsed = json_df.select(
    from_json(
        col("value"),
        "order_id INT, customer_id INT, amount INT, timestamp STRING"
    ).alias("data")
).select("data.*")

final_df = parsed \
    .withColumn("ingestion_time", current_timestamp()) \
    .dropDuplicates(["order_id"])

query = final_df.writeStream \
    .format("console") \
    .outputMode("append") \
    .start()

query.awaitTermination()
```

# AIRFLOW DAG

## retail_pipeline_dag.py

```python
from airflow import DAG
from airflow.operators.bash import BashOperator
from datetime import datetime

with DAG(
    dag_id='retail_pipeline',
    start_date=datetime(2025,1,1),
    schedule='@hourly',
    catchup=False
) as dag:

    producer = BashOperator(
        task_id='producer',
        bash_command='python kafka_producer.py'
    )

    consumer = BashOperator(
        task_id='consumer',
        bash_command='python spark_streaming_job.py'
    )

    producer >> consumer
```

# CDC INTERVIEW ANSWER

CDC means Change Data Capture.

Instead of loading entire table every time:

* load only changed records
* detect INSERT/UPDATE/DELETE

Used for:

* incremental pipelines
* lower cost
* faster processing

Example:

```sql
updated_at > last_run_timestamp
```

---

# SCD TYPE 2 INTERVIEW ANSWER

Maintain historical versions.

Example:
Customer address changed.

Instead of overwrite:

* expire old row
* insert new row

Columns:

```text
start_date
end_date
is_current
```

## 2. What is Lazy Evaluation?

**Answer**

Spark does not execute transformations immediately.

```python
df.filter(...)
df.select(...)
```

Execution happens only when action occurs:

```python
df.show()
df.count()
```

Benefit:

* query optimization
* reduced execution

## 6. What is Shuffle?

Most asked.

Data movement across executors.

Example:

```python
groupBy
join
distinct
repartition
```

Causes:

* network traffic
* disk I/O

Expensive operation.

---

## 7. Repartition vs Coalesce

Repartition:

```python
df.repartition(10)
```

* increase or decrease partitions
* shuffle

Coalesce:

```python
df.coalesce(2)
```

* decrease only
* minimal shuffle

---

memory only

Persist:

```python

```

memory + disk options

Use when DataFrame reused multiple times.
