# Python Backend Interview Revision Notes

## 1. Why are tuples immutable?

**Answer:**
A tuple is immutable because once it is created, its elements and structure cannot be modified. The immutability comes from the tuple data type itself, not from the use of parentheses `()`.

---

## 2. Can we modify elements inside a tuple?

**Answer:**
The tuple itself cannot be modified, but if it contains mutable objects like lists or dictionaries, those objects can be changed.

Example:

```python
t = ([1, 2], 3)
t[0].append(99)

print(t)
# ([1, 2, 99], 3)
```

---

## 3. What is Garbage Collection in Python?

**Answer:**
Python primarily uses reference counting for memory management. When an object's reference count reaches zero, its memory is released.

To handle circular references, Python also uses a cyclic garbage collector.

---

## 4. What are circular references?

**Answer:**
Circular references occur when two or more objects reference each other, preventing their reference count from reaching zero.

The cyclic garbage collector detects and removes these unreachable object graphs.

---

## 5. Difference between `if` and `==`

**Answer:**

* `==` compares two values and returns a boolean.
* `if` uses a boolean value to decide whether a block of code should execute.

Example:

```python
if x == 10:
    print("Equal")
```

---

## 6. Difference between List and Tuple

**Answer:**

| List                      | Tuple                              |
| ------------------------- | ---------------------------------- |
| Mutable                   | Immutable                          |
| More memory overhead      | More memory efficient              |
| Cannot be dictionary keys | Can be dictionary keys if hashable |
| Slower                    | Slightly faster                    |

---

## 7. When is a tuple hashable?

**Answer:**
A tuple is hashable if all of its elements are hashable.

Duplicate values do not affect hashability.

Example:

```python
t = (1, "python", 1)
hash(t)
```

---

## 8. Difference between `is` and `==`

**Answer:**

* `==` compares values.
* `is` compares object identity (memory location).

Example:

```python
a = [1,2]
b = [1,2]

a == b  # True
a is b  # False
```

---

## 9. Difference between Primary Key and Unique Constraint

**Answer:**

| Primary Key               | Unique Constraint            |
| ------------------------- | ---------------------------- |
| Only one per table        | Multiple allowed             |
| Cannot be NULL            | NULL allowed depending on DB |
| Identifies a row uniquely | Enforces uniqueness          |

---

## 10. Composite Index vs Separate Indexes

**Answer:**

* Composite indexes are useful when queries frequently use multiple columns together.
* Separate indexes are useful when columns are queried independently.

Example:

```sql
CREATE INDEX idx_customer_date
ON orders(customer_id, order_date);
```

---

## 11. How do you design safe database migrations?

**Answer:**

* Keep migrations small and incremental.
* Use `transaction.atomic()`.
* Test in staging.
* Keep backups before production deployment.
* Separate schema migrations from data migrations.

---

## 12. What if a migration fails in production?

**Answer:**

* Use transactions for rollback.
* Restore from backups if necessary.
* Fix and redeploy the migration.
* Validate data consistency afterward.

---

## 13. What is P95 Latency?

**Answer:**
P95 latency means 95% of requests complete within a certain time, while the slowest 5% take longer.

## 15. What is GIL?

**Answer:**
The Global Interpreter Lock allows only one thread to execute Python bytecode at a time in a CPython process.

## 16. Multithreading vs Multiprocessing

**Answer:**

| Multithreading          | Multiprocessing         |
| ----------------------- | ----------------------- |
| Best for I/O-bound work | Best for CPU-bound work |
| Shares memory           | Separate memory space   |
| Affected by GIL         | Not affected by GIL     |

## 17. Explain Concurrency in Python

**Answer:**
Concurrency means handling multiple tasks efficiently.

* Use multithreading or async for I/O-bound tasks.
* Use multiprocessing for CPU-bound tasks.
* Multiprocessing achieves true parallelism because each process has its own GIL.

## 1. Process vs Thread

### Answer

* A **process** is an independent execution unit with its own memory space.
* A **thread** is the smallest unit of execution within a process and shares memory with other threads in the same process.

### Python GIL Impact

* Python's **Global Interpreter Lock (GIL)** allows only one thread to execute Python bytecode at a time in a process.
* Because of this:

| Use Case        | Preferred       |
| --------------- | --------------- |
| I/O Bound Tasks | Multithreading  |
| CPU Bound Tasks | Multiprocessing |

Examples:

* I/O Bound → API calls, DB calls, file I/O
* CPU Bound → Image processing, ML training, large computations

---

## 2. Async Programming for APIs

### Question

How do you handle concurrent inbound and outbound requests in Python APIs?

### Answer

Use:

* `asyncio`
* `async def`
* `await`

This allows the event loop to process other requests while waiting for I/O operations.

Example frameworks:

* FastAPI
* aiohttp

Best for:

* API calls
* Database calls
* File operations

---

## 3. `def` vs `async def`

| Feature          | `def`       | `async def`  |
| ---------------- | ----------- | ------------ |
| Execution        | Synchronous | Asynchronous |
| Blocking         | Yes         | No           |
| Uses Event Loop  | No          | Yes          |
| Supports `await` | No          | Yes          |

Use:

* `def` → CPU work
* `async def` → I/O work

---

## 4. Blocking Calls in Async Functions

### Answer

Blocking operations inside `async def` stall the event loop.

Bad:

```python
time.sleep(5)
requests.get(url)
```

Good:

```python
await asyncio.sleep(5)
await client.get(url)
```

Use:

* `httpx.AsyncClient`
* `aiohttp`

### Fixed Endpoint

```python
@app.route('/users/<user_id>')
def get_user(user_id):

    if not user_id.isdigit():
        return jsonify({
            "error": "Invalid user id"
        }), 400

    user_id = int(user_id)

    user = users.get(user_id)

    if user is None:
        return jsonify({
            "error": "User not found"
        }), 404

    return jsonify(user), 200
```
