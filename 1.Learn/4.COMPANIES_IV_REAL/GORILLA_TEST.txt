## Interview Questions & Answers (Complete Revision Sheet)

### 1. Process vs Thread vs GIL

**Q:** Explain Process, Thread, and GIL.

**A:**

* A **Process** has its own memory space and is suitable for **CPU-bound** tasks.
* A **Thread** shares the same memory within a process and is suitable for **I/O-bound** tasks.
* Python's **Global Interpreter Lock (GIL)** allows only one thread to execute Python bytecode at a time.
* Use **threading** for network calls, file I/O, APIs.
* Use **multiprocessing** for CPU-intensive work.

---

### 2. CPU Heavy Work

**Q:** How do you handle CPU-heavy work?

**A:**

* Use **multiprocessing** or **ProcessPoolExecutor**.
* Offload heavy tasks to worker queues (Celery/RQ).
* Measure performance using profiling and benchmarking.

---

### 3. Multiple Workers

**Q:** What should you consider while using multiple workers?

**A:**

* Shared cache consistency
* Race conditions
* Memory usage
* Rate limiting
* Synchronization (Locks/Semaphores)

---

### 4. Concurrency vs Parallelism

**A:**

* **Concurrency:** Multiple tasks make progress together.
* **Parallelism:** Multiple tasks execute simultaneously on multiple CPU cores.

---

### 5. asyncio.to_thread vs ProcessPoolExecutor

**A:**
`asyncio.to_thread()`

* Blocking I/O
* File operations
* Network requests

`ProcessPoolExecutor`

* CPU-bound work
* Image processing
* ML inference
* Heavy computation

---

### 6. Dictionary & Set Complexity

* Average:

```

Search O(1)

Worst Case:

```
O(n)

Due to hash collisions.
