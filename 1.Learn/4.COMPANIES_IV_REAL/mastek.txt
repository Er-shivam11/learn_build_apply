# Mastek Interview Notes (Questions Asked So Far + Short Answers)

## 1. Find customers who placed more than 3 orders after 1st June 2026

```sql
SELECT customer_id,
       COUNT(order_id) AS order_count
FROM orders
WHERE order_date > '2026-06-01'
GROUP BY customer_id
HAVING COUNT(order_id) > 3;
```

**Concept:** `GROUP BY`, `HAVING`, Aggregation.

## 2. Explain your ELT flow.

**Answer:**

> We followed ELT instead of ETL. Data was first extracted and loaded into Snowflake, and transformations were performed inside Snowflake using dbt models.

---

## 3. Explain your dbt structure.

**Answer:**

```text
Raw Source
    ↓
Staging Models
    ↓
Intermediate Models
    ↓
Mart/Core Models
```

* **Staging:** Cleaning, renaming, standardization.
* **Intermediate:** Business logic and joins.
* **Mart:** Reporting and analytics datasets.

## 9. What is `st.session_state`?

**Answer:**

> `st.session_state` stores values across reruns and preserves user selections.

Example:

```python

```

## 13. Explain LEAD and LAG.

**Answer:**

* `LAG()` returns previous row value.
* `LEAD()` returns next row value.

Example:

```sql
SELECT
    month,
    sales,
    LAG(sales) OVER(ORDER BY month) AS previous_sales,
    LEAD(sales) OVER(ORDER BY month) AS next_sales
FROM sales;
```

## 14. Extract domain from email.

Example:

```text
abc@gmail.com → gmail.com
```

Snowflake solution:

```sql
SELECT SPLIT_PART(email, '@', 2) AS domain
FROM users;
```
