# Phase 1 – Arrays & Strings

## Step 1: Definition

### What are Arrays?

An **array** is a collection of elements stored **contiguously (next to each other) in memory**, and each element can be accessed using its **index**.

Example

```python
nums = [10, 20, 30, 40, 50]
```

Memory visualization

```
Index

0     1     2     3     4
┌───┬───┬───┬───┬───┐
│10 │20 │30 │40 │50 │
└───┴───┴───┴───┴───┘
```

Accessing any element:

```python
nums[2]
```

Output

```
30
```

This takes **O(1)** time because the address is calculated directly from the index.

---

## What are Strings?

A **string** is simply an array (sequence) of characters.

```python
name = "SHIVAM"
```

```
Index

0 1 2 3 4 5
S H I V A M
```

You can access characters the same way:

```python
name[3]
```

Output

```
V
```

So in interviews, **arrays and strings are often grouped together** because the traversal techniques are almost identical.

# Real-life Analogy

Imagine you're standing in front of a row of lockers.

```
Locker Number

0 1 2 3 4 5
```

Each locker stores one item.

```
0 → Shoes

1 → Books

2 → Laptop

3 → Bottle

4 → Bag
```

If I ask,

> "Bring me the item from locker number 2."

You immediately go to locker **2**.

You don't need to open lockers 0 and 1 first.

That's exactly how arrays work.

**Index = Locker Number**

# Important Operations

| Operation                                | Time Complexity |
| ---------------------------------------- | --------------- |
| Access by index                          | O(1)            |
| Update by index                          | O(1)            |
| Traverse all elements                    | O(n)            |
| Search (unsorted)                        | O(n)            |
| Insert at end (Python list, amortized)   | O(1)            |
| Insert at beginning                      | O(n)            |
| Delete from beginning                    | O(n)            |
| Delete from end (Python list, amortized) | O(1)            |
