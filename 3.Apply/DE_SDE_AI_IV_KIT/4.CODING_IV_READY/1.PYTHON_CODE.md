**Question to ask:**

> "Do I need the position/index of an element?"

* First Occurrence
* Last Occurrence
* All Occurrences
* Replace Negative with 0
* Square Every Element

Mental model:

# 3️⃣ Two Pointer Template

**Question to ask:**

> "Do I need to compare or modify from both ends?"

Use:

```python
l = 0

```

Examples:

* Reverse Array
* Palindrome Check

* Reverse Words
* Reverse Vowels

Mental model:

```text

↑         ↑
l         r
```

# 4️⃣ Range Loop Template

**Question to ask:**

> "Do I need to move with a custom step?"

Use:

```python
for i in range(start, stop, step):
```

Examples:

* Swap Adjacent Pairs

```python
for i in range(0, len(nums)-1, 2):
```

* Even indices

```python
for i in range(0, len(nums), 2):
```

* Odd indices

```python
for i in range(1, len(nums), 2):
```

Mental model:

```text
0 → 2 → 4 → 6
```

# 5️⃣ Build New Collection Template

**Question to ask:**

> "Do I want to create a filtered or transformed version?"

Use:

```python
result = []

for i in nums:
    if condition:
        result.append(i)
```

Examples:

* Remove Negatives
* Remove Zeros
* Keep Positives Only
* Multiply by 2
* Square Every Element

---

# 6️⃣ Seen/Notebook Template

**Question to ask:**

> "Have I seen this before?"

Use:

```python
seen = set()

for i in nums:
    if i in seen:
        # duplicate found
    else:
        seen.add(i)
```

Examples:

* Contains Duplicate
* First Unique Character
* Frequency Counting

Your analogy:

```text
See Rahul
↓
Have I seen Rahul before?
↓
No
↓
Write Rahul in notebook
```

---

# 7️⃣ Sliding Window Template

**Question to ask:**

> "Do I need a continuous subarray or substring?"

Use:

```python
left = 0

for right in range(len(nums)):
    # expand window

    while condition:
        left += 1
```

Examples:

* Maximum Average Subarray
* Longest Substring Without Repeating Characters
* Minimum Window Substring

---

# 8️⃣ Prefix Sum Template

**Question to ask:**

> "Do I need fast range sums?"

Use:

```python
prefix = [0]

for num in nums:
    prefix.append(prefix[-1] + num)
```

Examples:

* Range Sum Query
* Subarray Sum Equals K
* Pivot Index
