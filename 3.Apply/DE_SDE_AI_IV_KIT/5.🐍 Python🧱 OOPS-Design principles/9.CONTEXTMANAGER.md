
# Context Managers

## Definition

> **A Context Manager is an object that automatically manages resources such as files, database connections, locks, or network connections by setting them up before use and cleaning them up afterward. It is typically used with the `with` statement and implemented using the `__enter__()` and `__exit__()` methods.**

---

## One-Line Analogy

> **Think of a hotel: you check in (`__enter__()`), stay in the room (your code), and check out (`__exit__()`). The hotel automatically handles opening and closing your stay.**

---

# Real-Life Example (File Handling)

```python
with open("sample.txt", "w") as file:
    file.write("Hello Shivam")
```

### Output

```text
sample.txt created successfully
```

The file is **automatically closed**, even if an exception occurs.

---

# What Happens Internally?

```text
with open(...)

        ↓

__enter__()

        ↓

Resource Opened

        ↓

Your Code Executes

        ↓

__exit__()

        ↓

Resource Closed
```

---

# Without Context Manager

```python
file = open("sample.txt", "w")

file.write("Hello Shivam")

file.close()
```

If an exception occurs before `close()`, the file may remain open.

---

# With Context Manager

```python
with open("sample.txt", "w") as file:
    file.write("Hello Shivam")
```

Python guarantees the resource is cleaned up.

# Custom Context Manager

```python
class Database:

    def __enter__(self):
        print("Database Connected")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Database Closed")


with Database():
    print("Fetching Employees")
```

### Output

```text
Database Connected
Fetching Employees
Database Closed
```

# Production Examples

### File Handling

```python
with open("orders.csv") as file:
    data = file.read()
```

---

### Database Connection

```python
with database_connection() as conn:
    conn.execute(query)
```

---

### Thread Lock

```python
with lock:
    shared_data += 1
```

---

### Transaction

```python
with transaction:
    save_order()
```

# Why Use Context Managers?

Without them:

```python
connect()

try:
    process()
finally:
    disconnect()
```

With them:

```python
with Database():
    process()
```

Cleaner and safer.

---

# Advantages

* ✅ Automatic resource cleanup
* ✅ Exception safe
* ✅ Cleaner code
* ✅ Prevents resource leaks
* ✅ Widely used in production

---

# Drawbacks

* ❌ Slight learning curve
* ❌ Requires implementing `__enter__()` and `__exit__()` for custom managers

# ⭐ Interview Answer (30 Seconds)

> **"A Context Manager is an object that automatically manages the lifecycle of resources using the `with` statement. It acquires resources through `__enter__()` and releases them through `__exit__()`, ensuring proper cleanup even if exceptions occur. Context managers are commonly used for files, database connections, transactions, locks, and network resources."**
