# Iterators

## Definition

> **An iterator is an object that returns one element at a time from a collection using the `__next__()` method. It keeps track of its current position and raises `StopIteration` when no elements remain. An iterator is created from an iterable using the `iter()` function.**

---

## One-Line Analogy

> **Think of a TV remote: every time you press the "Next" button, it moves to the next channel. When there are no more channels, it stops.**

---

# How a `for` Loop Works Internally

When you write:

```python
orders = ["Laptop", "Mouse", "Keyboard"]

for order in orders:
    print(order)
```

Python actually does this internally:

```python
orders = ["Laptop", "Mouse", "Keyboard"]

iterator = iter(orders)

while True:
    try:
        item = next(iterator)
        print(item)
    except StopIteration:
        break
```

### Output

```text
Laptop
Mouse
Keyboard
```

# Custom Iterator Example

```python
class OrderIterator:

    def __init__(self):
        self.orders = ["Laptop", "Mouse", "Keyboard"]
        self.index = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.index >= len(self.orders):
            raise StopIteration

        order = self.orders[self.index]
        self.index += 1
        return order


orders = OrderIterator()

for order in orders:
    print(order)
```

### Output

```text
Laptop
Mouse
Keyboard
```

# Iterable vs Iterator

| Iterable                         | Iterator                               |
| -------------------------------- | -------------------------------------- |
| Collection of data               | Object that fetches one item at a time |
| Uses `__iter__()`                | Uses `__next__()`                      |
| Cannot use `next()` directly     | Can use `next()` directly              |
| Examples: list, tuple, set, dict | Created using `iter()`                 |

Example:

```python
orders = ["Laptop", "Mouse"]

print(iter(orders))

iterator = iter(orders)

print(next(iterator))
```

# Advantages

* ✅ Memory efficient
* ✅ Lazy evaluation (loads one item at a time)
* ✅ Useful for large datasets
* ✅ Foundation of `for` loops

---

# Drawbacks

* ❌ Can only move forward
* ❌ Once exhausted, it cannot be reused
* ❌ Raises `StopIteration` when finished

---

# Common Interview Questions

### Q1. What is an iterator?

> An object that returns one item at a time using `__next__()`.

---

### Q2. What is an iterable?

> An object that can produce an iterator using `iter()`.

---

### Q3. Difference between iterable and iterator?

> An iterable is a collection, while an iterator is an object that traverses that collection one element at a time.

---

### Q4. Which methods define an iterator?

> `__iter__()` and `__next__()`.

---

### Q5. Why is an iterator memory efficient?

> Because it produces one element at a time instead of loading everything into memory at once.

---

### Q6. What happens after the last element?

> `next()` raises a `StopIteration` exception.

---

# ⭐ Interview Answer (30 Seconds)

> **"An iterator is an object that returns one element at a time using the `__next__()` method while maintaining its current position. It is created from an iterable using `iter()`. Python's `for` loop internally creates an iterator and repeatedly calls `next()` until a `StopIteration` exception is raised. Iterators are memory efficient because they process data lazily, one item at a time."**
