# 1. Factory Pattern

## Definition

> **Factory Pattern creates objects without exposing the object creation logic to the client.**

### Without Factory

```python
class CardPayment:
    pass

payment = CardPayment()
```

---

### With Factory

```python
class CardPayment:

    def pay(self):
        print("Card Payment")


class UPIPayment:

    def pay(self):
        print("UPI Payment")


class PaymentFactory:

    @staticmethod
    def create_payment(method):

        if method == "card":
            return CardPayment()

        return UPIPayment()


payment = PaymentFactory.create_payment("card")

payment.pay()
```

### Output

```text
Card Payment
```

---

## Interview Line

> Factory decides which object to create.

---

# 2. Strategy Pattern

## Definition

> **Strategy Pattern allows selecting an algorithm or behavior at runtime.**

---

```python
class CardPayment:

    def pay(self):
        print("Card Payment")


class UPIPayment:

    def pay(self):
        print("UPI Payment")


class Checkout:

    def __init__(self, payment_method):
        self.payment_method = payment_method

    def process(self):
        self.payment_method.pay()


checkout = Checkout(UPIPayment())

checkout.process()
```

### Output

```text
UPI Payment
```

---

## Interview Line

> Strategy changes behavior at runtime.

---

# Factory vs Strategy

| Factory         | Strategy            |
| --------------- | ------------------- |
| Creates Object  | Uses Object         |
| Object Creation | Algorithm Selection |
| Which Object?   | Which Behavior?     |

---

# 3. Dependency Injection (DI)

## Definition

> **Dependency Injection means providing dependencies from outside instead of creating them inside the class.**

---

## Bad

```python
class MySQL:
    pass


class UserService:

    def __init__(self):
        self.db = MySQL()
```

Tightly coupled.

---

## Good

```python
class MySQL:
    pass


class UserService:

    def __init__(self, db):
        self.db = db


service = UserService(MySQL())
```

---

## Interview Line

> Don't create dependencies. Inject them.

---

# 4. Inversion of Control (IoC)

## Definition

> **IoC means transferring control of object creation and dependency management to an external framework or container.**

---

Without IoC

```python
service = UserService(MySQL())
```

You control everything.

---

With IoC

```text
Django
FastAPI
Spring

↓

Framework creates objects

↓

Framework injects dependencies

↓

You only write business logic
```

---

## Interview Line

> Framework controls object creation, not you.

---

# One Complete Example

This single example contains:

* Factory
* Strategy
* DI

```python
class CardPayment:

    def pay(self):
        print("Card Payment")


class UPIPayment:

    def pay(self):
        print("UPI Payment")


class PaymentFactory:

    @staticmethod
    def create(method):

        if method == "card":
            return CardPayment()

        return UPIPayment()


class Checkout:

    def __init__(self, payment):
        self.payment = payment

    def process(self):
        self.payment.pay()


payment = PaymentFactory.create("upi")

checkout = Checkout(payment)

checkout.process()
```

### Output

```text
UPI Payment
```

---

# What Happened?

```text
Factory
      ↓
Creates UPIPayment

DI
      ↓
Injects UPIPayment into Checkout

Strategy
      ↓
Checkout uses selected payment method

Output
      ↓
UPI Payment
```
