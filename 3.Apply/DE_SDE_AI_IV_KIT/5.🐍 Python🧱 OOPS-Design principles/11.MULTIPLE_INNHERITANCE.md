## Definition

> **Multiple Inheritance is an OOP feature where a child class inherits from more than one parent class, allowing it to reuse functionality from multiple sources. Python resolves method conflicts using MRO (Method Resolution Order).**

---

# One-Line Analogy

> **A Smartphone is both a Camera and a Phone.**

```text
SmartPhone

   ↑       ↑

Camera   Phone
```

---

# Basic Example

```python
class Payment:

    def payment(self):
        print("Payment Done")


class Discount:

    def discount(self):
        print("Discount Applied")


class Order(Payment, Discount):
    pass


order = Order()

order.payment()
order.discount()
```

### Output

```text
Payment Done
Discount Applied
```

---

# What Happens Internally?

```text
Order

  ↑
  │

Payment      Discount

  │             │

payment()   discount()
```

Order gets methods from both parents.

---

# Conflict Example

Both parents have same method.

```python
class Payment:

    def process(self):
        print("Payment Process")


class Discount:

    def process(self):
        print("Discount Process")


class Order(Payment, Discount):
    pass


order = Order()

order.process()
```

### Output

```text
Payment Process
```

Why?

Because Python follows **MRO**.

---

# MRO Flow

```python
print(Order.mro())
```

Output:

```text
[
 Order,
 Payment,
 Discount,
 object
]
```

Python searches top to bottom.

```text
Order

↓

Payment

↓

Discount

↓

object
```

First match wins.

---

# Change One Line → Change Output

```python
class Order(Discount, Payment):
    pass
```

Now:

```python
order.process()
```

Output:

```text
Discount Process
```

MRO becomes:

```text
Order

↓

Discount

↓

Payment

↓

object
```

# Real Project Example

```python
class LoginMixin:

    def login(self):
        print("Login Success")


class PermissionMixin:

    def permission(self):
        print("Permission Granted")


class User(LoginMixin, PermissionMixin):
    pass


user = User()

user.login()
user.permission()
```

### Output

```text
Login Success
Permission Granted
```

This is extremely common in Django.

# Why Use Multiple Inheritance?

Instead of duplicating code:

```python
class User:
    pass

class Admin:
    pass
```

Reuse behavior:

```python
class LoginMixin:
    pass

class PermissionMixin:
    pass

class User(LoginMixin, PermissionMixin):
    pass
```

---

# Advantages

* ✅ Code reuse
* ✅ Combines multiple behaviors
* ✅ Useful for Mixins
* ✅ Reduces duplication

---

# Drawbacks

* ❌ Diamond Problem
* ❌ MRO complexity
* ❌ Harder debugging
* ❌ Tight coupling

# Diamond Problem

```python
        A
      /   \
     B     C
      \   /
        D
```

Example:

```python
class A:
    def show(self):
        print("A")

class B(A):
    pass

class C(A):
    pass

class D(B, C):
    pass
```

Question:

```python
D().show()
```

Should Python use:

```text
B → A
```

or

```text
C → A
```

Python solves this using **C3 Linearization (MRO)**.

# Common Interview Questions

### Q1. What is Multiple Inheritance?

> A child class inheriting from multiple parent classes.

---

### Q2. How does Python resolve method conflicts?

> Using MRO (Method Resolution Order).

---

### Q3. What is the Diamond Problem?

> When the same ancestor appears through multiple inheritance paths.

---

### Q4. How does Python solve the Diamond Problem?

> Using C3 Linearization (MRO).

---

### Q5. Real-world use?

> Mixins in Django and reusable behavior classes.

# ⭐ Interview Answer (30 Seconds)

> **"Multiple Inheritance allows a class to inherit from more than one parent class. It enables code reuse and combining behaviors from multiple sources. Multiple inheritance is commonly used through Mixins in frameworks like Django."**
