# 14. JOINS

## Definition

**A JOIN combines rows from two or more tables based on a related column.**

---

## Why

Data is normalized into multiple tables to avoid duplication.

JOIN helps retrieve related information.

---

## Analogy

Imagine a school.

One register stores Students.

Another register stores Marks.

To see **Student Name + Marks**, both registers must be combined.

That is exactly what JOIN does.

---

## Types

* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* FULL OUTER JOIN

---

## INNER JOIN

Returns only matching rows.

### Syntax

```sql
SELECT *
FROM table1
INNER JOIN table2
ON table1.id = table2.id;
```

### Fully Commented SQL

```sql
SELECT

c.customer_id,          -- Customer Id

c.name,                 -- Customer Name

o.product,              -- Product Purchased

o.amount                -- Purchase Amount

FROM customers c

INNER JOIN orders o

ON c.customer_id = o.customer_id;   -- Matching Column
```

### Execution

```
Customers
      │
      │ customer_id
      ▼
Orders

Only matching rows returned.
```

### Drawbacks

* Missing records are ignored.
* Non-matching rows are lost.

---

## LEFT JOIN

Returns all rows from the left table.

Matching rows are returned from the right table.

If no match exists → NULL.

### Syntax

```sql
SELECT *
FROM customers
LEFT JOIN orders
ON customers.customer_id = orders.customer_id;
```

### Example

```
Customer

1 Shivam
2 Rahul
3 Amit

Orders

1 Laptop
2 Phone
```

Result

```
Shivam Laptop

Rahul Phone

Amit NULL
```

### Drawback

Large joins may return many NULL values.

---

## RIGHT JOIN

Exactly opposite of LEFT JOIN.

Returns all rows from the right table.

### Drawback

Rarely used in production because LEFT JOIN is easier to read.

---

## FULL OUTER JOIN

Returns every row from both tables.

Matching rows merge together.

Non-matching rows contain NULL.

### Drawback

Produces very large result sets.

Often expensive.

---

```

---------------

---------------

RIGHT

---------------

```

# 15. UNION

## Definition

UNION combines results of two SELECT queries and removes duplicate rows.

---

## Why

Combine similar datasets.

---

## Analogy

Two classroom attendance sheets merged into one while removing duplicate students.

---

## Syntax

```sql
SELECT city FROM customers

UNION

SELECT city FROM suppliers;
```

---

## Fully Commented SQL

```sql
SELECT city

FROM customers

UNION                   -- Removes Duplicate Rows

SELECT city

FROM suppliers;
```

---

## Drawbacks

Sorting is required to remove duplicates.

Slightly slower.

---

# UNION ALL

Keeps duplicates.

Much faster.

---

# Quick Revision

```

Removes Duplicate

---------------

Keeps Duplicate
```

# 16. INTERSECT

## Definition

Returns only common rows from both SELECT statements.

---

## Analogy

Students enrolled in both Cricket and Football.

---

## Syntax

```sql
SELECT name

FROM employees

INTERSECT

SELECT name

FROM managers;
```

---

## Example

Employees

```
Shivam

Rahul

Amit
```

Managers

```
Rahul

Neha
```

Result

```
Rahul
```

---

## Drawback

Less commonly used.

Can often be replaced using JOIN.

---

## Quick Revision

Common Values Only.

---

# 17. EXCEPT

## Definition

Returns rows from the first query that are NOT present in the second query.

---

## Analogy

Students registered in school but not in the library.

---

## Syntax

```sql
SELECT name

FROM employees

EXCEPT

SELECT name

FROM managers;
```

Result

```
Shivam

Amit
```

---

## Drawback

Order matters.

A EXCEPT B

≠

B EXCEPT A

---

# 18. SEMI JOIN

## Definition

Returns rows from the first table only if a matching row exists in another table.

SQL has no explicit SEMI JOIN keyword.

It is implemented using EXISTS.

---

## Why

Efficiently checks whether related data exists without returning columns from the second table.

---

## Analogy

Checking whether a student has paid fees.

You only need the student list—not the fee receipt details.

---

## Syntax

```sql
SELECT *

FROM customers c

WHERE EXISTS (

SELECT 1

FROM orders o

WHERE c.customer_id=o.customer_id

);
```

---

## Drawback

Cannot return columns from the second table.

---

## Quick Revision

Yes

Return Customer.

# 19. ANTI JOIN

## Definition

Returns rows that do NOT have matching rows in another table.

Implemented using NOT EXISTS.

---

## Analogy

Students who have NOT submitted assignments.

---

## Syntax

```sql
SELECT *

FROM customers c

WHERE NOT EXISTS (

SELECT 1

FROM orders o

WHERE c.customer_id=o.customer_id

);
```

---

## Drawback

Performance depends on indexing.
