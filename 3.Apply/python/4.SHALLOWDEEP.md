# Shallow Copy vs Deep Copy

## Definition

> **A shallow copy creates a new outer object but shares references to nested objects with the original. A deep copy creates a completely independent copy of both the outer object and all nested objects recursively.**

---

## One-Line Analogy

> **A shallow copy is like photocopying a house map but using the same furniture. A deep copy is like building a completely new house with new furniture.**

---

# Real-Life Example (E-commerce)

**Scenario:** An order contains customer details. We duplicate the order before editing it.

```python
import copy

order = {
    "id": 101,
    "items": ["Laptop", "Mouse"]
}

shallow = copy.copy(order)
deep = copy.deepcopy(order)

shallow["items"].append("Keyboard")
deep["items"].append("Monitor")

print("Original :", order)
print("Shallow :", shallow)
print("Deep     :", deep)
```

### Output

```text
Original : {'id': 101, 'items': ['Laptop', 'Mouse', 'Keyboard']}
Shallow : {'id': 101, 'items': ['Laptop', 'Mouse', 'Keyboard']}
Deep     : {'id': 101, 'items': ['Laptop', 'Mouse', 'Monitor']}
```

---

# What Happens Internally?

## Original Object

```text
order
   │
   ▼

Dictionary
   │
   ├── id → 101
   │
   └── items ─────────► ["Laptop","Mouse"]
```

---

## Shallow Copy

```python
shallow = copy.copy(order)
```

```text
order ─────────────┐
                   │
                   ▼
              ["Laptop","Mouse"]
                   ▲
                   │
shallow ───────────┘
```

Both dictionaries are different, **but the `items` list is shared**.

When you do

```python
shallow["items"].append("Keyboard")
```

Both see the change.

---

## Deep Copy

```python
deep = copy.deepcopy(order)
```

```text
order ─────► ["Laptop","Mouse"]

deep ──────► ["Laptop","Mouse"]
```

Each object has its **own independent list**.

Changing one does **not** affect the other.

---

# When to Use?

### Shallow Copy

Use when:

* Nested objects don't need to be modified.
* You want better performance.
* Sharing nested data is acceptable.

---

### Deep Copy

Use when:

* You need a completely independent object.
* Nested lists or dictionaries will be modified.
* You want to avoid side effects.

---

# Advantages

### Shallow Copy

* ✅ Faster
* ✅ Uses less memory
* ✅ Suitable for simple structures

---

### Deep Copy

* ✅ Completely independent copy
* ✅ Safe for nested mutable objects
* ✅ No accidental shared changes

---

# Drawbacks

### Shallow Copy

* ❌ Nested mutable objects are shared.
* ❌ Can lead to unexpected bugs.

---

### Deep Copy

* ❌ Slower
* ❌ Uses more memory
* ❌ Can be expensive for very large objects

---

# Common Interview Questions

### Q1. What is a shallow copy?

> A new outer object is created, but nested objects are shared with the original.

---

### Q2. What is a deep copy?

> A completely independent copy of the object and all nested objects.

---

### Q3. Which module is used?

```python
import copy
```

---

### Q4. How do you create them?

```python
copy.copy(obj)
```

```python
copy.deepcopy(obj)
```

---

### Q5. Why is shallow copy dangerous?

> Because modifying a shared nested mutable object affects both the original and the copied object.

---

# ⭐ Interview Answer (30 Seconds)

> **"A shallow copy creates a new outer object while sharing references to nested mutable objects. A deep copy recursively creates completely independent copies of all nested objects. Shallow copies are faster and use less memory, whereas deep copies provide complete isolation and are safer when modifying nested data."**
