# Generators

## Definition

> **A generator is a special type of iterator that produces one value at a time using the `yield` keyword instead of returning all values at once. It supports lazy evaluation, making it highly memory efficient for processing large datasets.**

---

## One-Line Analogy

> **Think of a vending machine: instead of giving you all snacks at once, it dispenses one snack each time you press the button.**

---

# Real-Life Example (E-commerce)

```python
def orders():

    yield "Laptop"
    yield "Mouse"
    yield "Keyboard"


for order in orders():
    print(order)
```

### Output

```text
Laptop
Mouse
Keyboard
```

# Generator vs Normal Function

## Normal Function

```python
def orders():
    return ["Laptop", "Mouse", "Keyboard"]


print(orders())
```

### Output

```text
['Laptop', 'Mouse', 'Keyboard']
```

* Creates the **entire list** in memory.
* Returns everything at once.

---

## Generator Function

```python
def orders():

    yield "Laptop"
    yield "Mouse"
    yield "Keyboard"


print(next(orders()))
```

### Output

```text
Laptop
```

* Creates **nothing until requested**.
* Produces **one item at a time**.

---

# Generator with `next()`

```python
def orders():

    yield "Laptop"
    yield "Mouse"
    yield "Keyboard"


g = orders()

print(next(g))
print(next(g))
print(next(g))
```

### Output

```text
Laptop
Mouse
Keyboard
```

# Real Production Example (Large Log File)

```python
def read_logs():

    for i in range(1, 6):
        yield f"Processing Log {i}"


for log in read_logs():
    print(log)
```

### Output

```text
Processing Log 1
Processing Log 2
Processing Log 3
Processing Log 4
Processing Log 5
```

Imagine this is **5 million log records**. A generator processes them one by one instead of loading all into memory.

# Generator Expression

Like list comprehension, but uses `()`.

```python
numbers = (x * x for x in range(5))

for num in numbers:
    print(num)
```

### Output

```text
0
1
4
9
16
```

# Generator vs Iterator

| Generator                             | Iterator                           |
| ------------------------------------- | ---------------------------------- |
| Uses `yield`                          | Uses `__iter__()` and `__next__()` |
| Python creates iterator automatically | You implement iterator manually    |
| Less code                             | More code                          |
| Memory efficient                      | Memory efficient                   |
| Easier to write                       | More control                       |

---

# Advantages

* ✅ Memory efficient
* ✅ Lazy evaluation
* ✅ Faster for large datasets
* ✅ Cleaner than custom iterators
* ✅ Ideal for ETL, file processing, APIs

---

# Drawbacks

* ❌ Can iterate only once
* ❌ No random indexing
* ❌ Cannot know length without consuming it

---

# Common Interview Questions

### Q1. What is a generator?

> A special iterator that produces values one at a time using `yield`.

---

### Q2. Difference between `return` and `yield`?

* `return` → Ends the function and returns one final value.
* `yield` → Pauses the function, saves its state, and resumes from the same point on the next call.

---

### Q3. Why are generators memory efficient?

> Because they generate values lazily, producing one item at a time instead of storing the entire collection in memory.

---

### Q4. Are generators iterators?

> Yes. Every generator is an iterator, but not every iterator is a generator.

---

### Q5. When would you use generators?

* Reading large files
* ETL pipelines
* Streaming APIs
* Database record processing
* Infinite sequences

---

# ⭐ Interview Answer (30 Seconds)

> **"A generator is a special type of iterator that uses the `yield` keyword to produce values one at a time instead of returning all values at once. It supports lazy evaluation, making it memory efficient for processing large datasets such as log files, ETL pipelines, database records, and streaming APIs. Since every generator is an iterator, it can be used directly in `for` loops or with `next()`."**
